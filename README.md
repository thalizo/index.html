# Futebol Arcade

Jogo de futebol arcade em HTML, com clubes do Brasileirão, modo campeonato e quadra de futsal.

## Como jogar

Abra `thalesfutindex.html` com a extensão Live Server no VS Code. O servidor local permite carregar as músicas do jogo.

## Arquivos

- `thalesfutindex.html`: jogo.
- `trilha.mp3`: toca em loop somente enquanto o painel do Brasileirão está aberto; para ao sair do painel ou iniciar uma partida.
- `trilha-creditos.mp3`: música dos créditos.
